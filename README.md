> My hands-on journey toward becoming a **production-ready AI engineer**, with a focus on building reliable AI applications, RAG systems, agents, evaluations, and security guardrails.

## Why this repository exists

I'm documenting what I learn, build, test, and improve as I prepare for AI engineering roles. The goal is not simply to complete courses. It is to develop the engineering skills needed to take an AI application from an idea to a working, tested, and deployable product.

This repository will contain my learning notes, small exercises, experiments, decisions, and progress logs. Larger portfolio projects will have their own repositories and will be linked here when ready.

## My learning approach

I follow a **skill-based, flexible schedule**. I move forward when I can demonstrate understanding, rather than waiting for a fixed number of days.

Each task has five checkpoints:

1. **Learn:** Understand the concepts and explain them in my own words.
2. **Build:** Implement a small, working example.
3. **Test:** Check normal inputs, edge cases, and failure cases.
4. **Evaluate:** Consider accuracy, reliability, security, performance, or cost where relevant.
5. **Document:** Record what worked, what failed, how I fixed it, and what I would improve.

## Portfolio direction

My goal is to build a small number of substantial, well-documented projects that demonstrate:

- **End-to-end development:** Python/FastAPI services, data flow, APIs, and useful interfaces.
- **AI capabilities:** RAG, retrieval evaluation, tool-using agents, and appropriate model choices.
- **Safety and reliability:** Input validation, access control, prompt-injection testing, guardrails, and evaluation suites.
- **Production practices:** Automated tests, Docker, configuration management, observability, and deployment.

Each published project will include setup instructions, a clear architecture, tests, limitations, and measurable results where possible.

## What success looks like

At the end of this journey, I want to be able to **design, build, evaluate, secure, deploy, and explain** real AI applications—and show evidence of those skills through working code and thoughtful engineering documentation.
